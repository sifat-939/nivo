Nivo is an offline accounting desktop application based on Frappe Books (AGPL-3.0-only).

This release removes the remaining item-list Tax columns, fixes deep-page reload/filter/save edge cases, and includes a 57-page Bengali user guide with 51 synthetic screenshots. It also improves document posting safety, list filtering and pagination, salary entry behaviour and Cash/Bank reporting. It also includes the Accounts and HR modules, Nivo branding and simplified navigation.

Windows 10/11 (64-bit): download the file ending in **-setup.exe** to install. The **-portable.exe** file starts without installation; company data still lives separately in the user profile. Installers are unsigned, so Windows may show an unknown-publisher warning. Verify SHA256SUMS.txt against your download.

Back up existing company databases before upgrading. Legacy imports may still require business-specific opening balances, payment allocations and stock reconciliation; this release does not invent those records or certify an old import as complete.

Linux: use the AppImage and the installer instructions in docs/installation.md. Automatic upstream updates remain disabled.

Download **Nivo-Bangla-Guide.pdf** for the Bengali tutorial. It contains synthetic example data only.
